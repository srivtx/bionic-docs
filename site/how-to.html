Guide

How to install and use

Store listings are pending, so the extension is built from source and loaded unpacked. It is a Manifest V3 extension; both targets are produced by one build.

Build the extension

You need Bun and the repository.

git clone https://github.com/srivtx/bionic-docs
cd bionic-docs
bun install
bun run build

The build writes dist/chrome and dist/firefox. It bundles PDF.js, its worker, cmaps, and standard fonts locally, so the extension loads no remote code.

Load it in Chrome or Edge

  1. Open the extensions page

    Go to chrome://extensions in Chrome (or edge://extensions in Edge).

  2. Turn on Developer mode

    The toggle is in the top corner of the page.

  3. Load unpacked

    Choose Load unpacked and select the dist/chrome directory. The extension appears in the toolbar.

Load it in Firefox

  1. Open about:debugging

    Enter about:debugging#/runtime/this-firefox in the address bar.

  2. Load a temporary add-on

    Choose Load Temporary Add-on… and select dist/firefox/manifest.json.

  3. Note the floor

    Firefox 140 or newer, because the manifest uses data_collection_permissions, which earlier versions do not understand. A temporary add-on is removed when Firefox closes.

Open a document

Click the toolbar icon to open the popup, then:

  • Open current document — for a PDF that is already open in a tab, the reader loads that URL. If the active tab is not a PDF, it falls back to the file picker.
  • Open a file… — pick a PDF or EPUB from disk. You can also drag a document anywhere onto the reader page.

There is a keyboard shortcut as well: press Ctrl/Cmd + Shift + O to open the current document at any time.

Use the reader

The reader has a small toolbar across the top:

Reader controls.
ControlWhat it does
ModeChoose Classic, Half, Vowel anchor, Low distraction, or Custom rule. The change applies live to the open document.
IntensityMove the slider to change how much of each word is emphasized. It also applies live, with no reload.
ContentsOpens a collapsible panel: for a PDF it lists each page by number and the first line of text on it, and for an EPUB it uses the document's own table of contents. Click an entry to jump to it. The panel is built the first time you open it.
‹ and ›Go to the previous or next page in a PDF, or the previous or next chapter in an EPUB. The counter between them shows where you are.
Open fileChoose another document without leaving the reader.

Navigation also works from the keyboard: ← and →, or PageUp and PageDown, move to the previous or next page or chapter; Home and End jump to the first or last; and C toggles the Contents panel (Esc closes it).

When you open a document you have read before, the reader offers to resume its last page or chapter. It remembers up to 25 documents.

Settings are stored by the extension, so the next document opens with the mode and intensity you last chose.

Local file:// PDFs

To open a PDF from a file:// path, the extension needs permission to read local files. In chrome://extensions, open bionic-docs details and enable Allow access to file URLs. Without it, the fetch of the local document is blocked and the reader reports that it could not load the file.

Verify a build

The same commands CI runs:

bun test
bun run build
node scripts/verify-build.mjs
bunx web-ext lint --source-dir dist/firefox
