FAQ

Frequently asked questions

Short, direct answers. Where a claim has a limit, the limit is stated.

Is it free and open source?

Yes. Bionic Docs is MIT licensed and the source is on GitHub. It is not affiliated with Bionic Reading GmbH.

Does it work on scanned PDFs?

No. A scanned page is an image with no text layer, so there is nothing to extract and the page renders empty. OCR is out of scope in this version. If a document has a real text layer, it works.

Does it upload my files?

No. There is no server and no analytics. Files are parsed in the extension page, and the only fetch in the codebase is the reader loading a document URL you explicitly opened. See the privacy page for the exact model.

Why does a PDF look like plain text instead of the original page?

PDFs are shown as reflowed text, not the original layout. The reader extracts the text layer and rebuilds lines, then emphasizes them. Complex multi-column or design-heavy pages read in extraction order, so columns can interleave and tables can lose alignment. That is the trade for applying fixation to the text.

Does it work in Firefox?

Yes, from Firefox 140. The manifest uses data_collection_permissions, which earlier versions do not understand. The Chrome build targets Chrome 116 and newer, and also loads in Edge.

What happens to my files?

Nothing is stored. The bytes are read into memory, parsed in the extension page, and released when you close the reader. Only the reading settings — mode, intensity, and so on — are persisted, using the extension's storage permission.

Can I use it offline?

Yes, by design. Nothing about reading, emphasis, or navigation needs the network. The only time the network is touched at all is when you ask it to open a document that already lives at a URL.

Is it on the Chrome Web Store or addons.mozilla.org?

Store listings are pending. For now you build both targets from source and load them unpacked; the how-to has the steps.
