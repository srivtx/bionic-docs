    What it does, and what it never does

    What happens to a file

    A document you open is handled entirely inside the extension page, in this order:

    1. The first bytes are sniffed: %PDF takes the PDF path, PK takes the EPUB path.
    2. An EPUB is unzipped locally with fflate. The package is read for its title, spine, and table of contents, and each chapter is sanitized before it is rendered.
    3. A PDF's text layer is extracted with the locally bundled PDF.js and rebuilt into lines. The original layout is not reproduced.
    4. The chapter or page is rendered, then the same fixation step bolds the leading letters of each word.

    Privacy, exactly

    There is no server. The extension makes no network requests for content, has no analytics, and has no account. It does not keep your documents; it stores your reading settings and the last page or chapter for each document.

    The only fetch in the codebase loads the document URL you explicitly opened, such as a PDF already in a tab. A file you choose or drop is read from disk and is never sent anywhere.

    PDF.js and fflate are bundled into the package; no remote code is fetched or evaluated at runtime. EPUB chapters are sanitized before insertion: scripts, event handlers, and javascript: URLs are removed.

    What it does not do

    The limitations are part of the contract, not footnotes.

    • Scanned PDFs have no text layer and render as empty pages. OCR is out of scope in this version.
    • PDFs are shown as reflowed text, not the original layout. Complex multi-column or design-heavy pages read in extraction order.
    • EPUB rendering is intentionally minimal: no pagination and no custom book CSS beyond the sanitized chapter markup.
    • The Firefox floor is 140, because data_collection_permissions is only understood from that version.

    Install

    Store listings are pending. Build both targets from source, then load the unpacked extension.

    git clone https://github.com/srivtx/bionic-docs && cd bionic-docs && bun install && bun run build

    Chrome and Edge load dist/chrome; Firefox loads dist/firefox/manifest.json. The how-to has the exact steps.

    Once built, press Ctrl/Cmd + Shift + O to open the current document at any time.
