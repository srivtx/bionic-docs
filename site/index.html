    What it does

    A reader that leaves your document alone

    Most bionic tools strip a PDF down to plain text. Bionic Docs keeps the page and puts the emphasis on top of it.

    Pages as they were printed

    PDF.js draws each page to a canvas: images, diagrams, colours and all. The text is laid back over it in the same position and width, then emphasized, so columns, captions and equations keep their shape.

    How it works

    Sniff, parse, emphasize

    Three steps, all inside the extension page. The document is never parsed anywhere else.

    1. 01

      Sniff

      The first bytes decide the path: %PDF- goes to PDF.js, a PK zip with an EPUB container goes to the book reader. File names are not trusted.

    2. 02

      Parse on device

      A bundled PDF.js renders each page and reports where its text sits. An EPUB is unzipped with fflate; its OPF gives the spine, its nav or NCX the contents.

    3. 03

      Emphasize

      The fixation step wraps each word's opening in <b>. It only touches text nodes, so a mode change repaints in place and the original bytes are never modified.

    Privacy

    There is no server.

    Bionic Docs has nowhere to send your document. There is no backend, no analytics and no account, and a test fails the build if a network call appears anywhere in the source except the one that loads the file you opened.

    • PDF.js, its worker, cmaps and fonts are bundled
    • No eval, no remote scripts, a strict extension CSP
    • EPUB chapters are sanitized before they are shown

    Honest limits

    What it does not do

    The limits are part of the contract, not footnotes.

    Scanned PDFs

    A scan has no text layer, so the page is shown as the image it is, without emphasis. OCR is out of scope for now.

    Embedded fonts

    Emphasized text is drawn in the browser's own fonts, stretched to the original width, so letter shapes can differ from the document's.

    Special glyphs

    Text PDF.js paints inside transparency groups or as Type 3 glyphs keeps its original look and does not get the emphasis.

    Book styling

    EPUB rendering is intentionally minimal: no pagination and no publisher CSS beyond the sanitized chapter markup.

    FAQ

    Questions, answered plainly

    Does my document get uploaded anywhere?

    No. The file is read and parsed inside the extension page. There is no server to send it to, and the source is checked by a test that fails on any other network call.

    Will the PDF still look like the PDF?

    Yes. Each page is drawn as it was printed, figures and colours included, and the emphasized text sits in the same place on top. Only the letter shapes of the emphasized text can differ, because the browser's fonts stand in for the embedded ones.

    Can I open PDFs from my computer?

    Yes. Use Open a file… in the popup, or drag a file onto the reader. To open file:// PDFs that are already in a tab, allow file access for the extension in your browser's extension settings.

    Does it work offline?

    Yes. Everything it needs, PDF.js and its fonts included, is in the package. Nothing is fetched at run time.

    Why does Firefox need version 140?

    The manifest declares that the extension collects no data, and Firefox only understands that declaration from version 140.

    Is this Bionic Reading?

    No. It is an independent, MIT-licensed project that uses its own fixation algorithm, shared with its sibling Bionic Page. It is not affiliated with Bionic Reading GmbH.
